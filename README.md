A 4 KB Python chess engine: 0x88 board, negamax alpha-beta with quiescence, transposition table, null-move pruning, repetition avoidance and piece-square tables. It plays the make.fun house gauntlet through the env.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
